La web de pruebas se puede añadir a la pantalla de inicio. Esto instala un acceso tipo app, no el paquete nativo definitivo.

Android

  1. Abre esta página en Chrome.
  2. Abre el menú ⋮ y elige Instalar aplicación o Añadir a pantalla de inicio.

iPhone

  1. Abre esta página en Safari.
  2. Toca Compartir.
  3. Elige Añadir a pantalla de inicio.
  4. Confirma con Añadir.
