Activar el servidor SURVIVAL

En un PC con Docker instalado, descarga el proyecto desde GitHub y ejecuta:

docker compose up -d

Después descarga un modelo de IA:

docker exec -it survival-ollama ollama pull llama3.2:3b

Abre el panel desde ese equipo o desde otro dispositivo de la misma red.
