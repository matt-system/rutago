Biblioteca offline · Kiwix

Servidor Kiwix: comprobando...

ZIM / OFFLINE

Cuando agregues archivos .zim a la carpeta data/zim del servidor, Kiwix los publicará aquí para leerlos sin conexión.

Catálogo de contenidos ↗
Los archivos ZIM no se incluyen en GitHub porque pueden ocupar varios GB. Descarga los que necesites desde el catálogo y colócalos en survival/data/zim.

Servidor cartográfico · TileServer GL

Servidor de mapas: comprobando...

MBTILES / OFFLINE

El servidor publica mapas vectoriales desde archivos .mbtiles almacenados en data/maps.

Buscar mapas MBTiles ↗
Para tener mapas reales sin Internet, descarga un archivo MBTiles de tu región y guárdalo en survival/data/maps. Los datos cartográficos no se distribuyen con esta app. Verifica licencia y atribución de cada mapa.

IA local · Ollama + Qdrant

Buscando servicios locales...

RAG LOCAL
Soy el asistente local de SURVIVAL. Cuando el servidor esté activo, podré responder usando los documentos que incorpores a tu biblioteca.
Las preguntas se procesan en tu equipo con Ollama. Qdrant almacena vectores de tus documentos para recuperar fragmentos relevantes antes de generar cada respuesta.

Agregar conocimiento a la memoria

Pega el texto de un manual, protocolo o documento para indexarlo localmente. Luego podrás preguntarle al asistente sobre su contenido.

Activar el servidor SURVIVAL

En un PC con Docker instalado, descarga el proyecto desde GitHub y ejecuta:

docker compose up -d

Después descarga un modelo de IA:

docker exec -it survival-ollama ollama pull llama3.2:3b

Abre el panel desde ese equipo o desde otro dispositivo de la misma red.
