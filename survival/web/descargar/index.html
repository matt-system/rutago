ANDROID · APK

Descargar para Android

Aplicación Android de prueba con biblioteca offline, asistente basado en las guías y chat cercano preparado para Bluetooth.

↓ DESCARGAR APK
Archivo APK · descarga directa · versión de prueba
  1. Descarga el archivo APK en tu teléfono.
  2. Abre el archivo descargado y autoriza la instalación si Android lo solicita.
  3. Abre SURVIVAL y concede los permisos necesarios para Bluetooth.
Si el enlace indica que el archivo aún no está disponible, espera a que termine la primera publicación de la versión Android.
IPHONE · INSTALACIÓN WEB

Instalar en iPhone

La versión nativa iOS todavía no está firmada para instalarse desde App Store o TestFlight. Mientras tanto, puedes añadir la versión web de SURVIVAL a la pantalla de inicio, como una app.

ABRIR SURVIVAL EN IPHONE ↗
  1. Abre SURVIVAL usando Safari en tu iPhone.
  2. Toca el botón Compartir.
  3. Elige «Añadir a pantalla de inicio» y confirma.
  4. Abre SURVIVAL desde el nuevo icono.
Esta versión web permite consultar la biblioteca y usar las funciones web disponibles. No incluye el chat Bluetooth nativo entre teléfonos. La app iOS completa llegará cuando esté firmada y distribuida por Apple.
