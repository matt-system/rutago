ANDROID · BUILD DE PRUEBA

Instalar en Android

Esta versión abre directamente en el Asistente offline, incluye la biblioteca de guías y mantiene el Chat cercano por Bluetooth. Descarga el APK desde el artefacto de compilación.

Descargar SURVIVAL para Android ↗
Archivo: survival-android-debug · APK de depuración · asistente offline + chat BLE
  1. Abre el enlace y descarga el artefacto survival-android-debug (ZIP).
  2. Descomprime el ZIP y abre app-debug.apk.
  3. Si Android lo solicita, autoriza temporalmente la instalación desde esa fuente.
  4. Abre SURVIVAL y concede los permisos Bluetooth cuando los pida.
Es una compilación de prueba, no una versión certificada para emergencias. El asistente consulta localmente las guías incluidas. El chat transmite por Bluetooth cuando encuentra otro teléfono compatible; falta validar el intercambio real entre equipos físicos sin Internet.
IPHONE · DISTRIBUCIÓN PENDIENTE

Instalar en iPhone

La compilación iOS actual pasó la compilación para simulador, pero no es un archivo instalable en un iPhone real. Para distribuirla necesitamos firmarla y publicarla mediante TestFlight o un canal autorizado de Apple.
