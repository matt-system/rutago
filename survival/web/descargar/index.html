ANDROID · BUILD DE PRUEBA

Instalar en Android

Descarga el paquete de instalación generado para esta versión. GitHub entrega el APK dentro de un archivo ZIP.

Descargar SURVIVAL para Android ↗
Archivo: survival-android-debug · APK de depuración · versión BLE fragmentada
  1. Abre el enlace y descarga el artefacto survival-android-debug (ZIP).
  2. Descomprime el ZIP y abre app-debug.apk.
  3. Si Android lo solicita, autoriza temporalmente la instalación desde esa fuente.
  4. Abre SURVIVAL y concede los permisos Bluetooth cuando los pida.
Esta es una compilación de prueba, no una versión certificada para emergencias. La comunicación BLE todavía debe probarse entre teléfonos físicos, sin Wi-Fi ni datos móviles.
